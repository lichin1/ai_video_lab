# 一天一AI 知識庫

把《數位時代》「一天一AI」專欄整理成：原文的個人離線封存、文章分類、職場能力應用藍圖，以及每篇文章對應的可安裝 skill 或流程。

## 流程

| 步驟 | 指令 / 檔案 | 狀態 |
|---|---|---|
| 1. 爬取原文與圖片 | `python3 -I scripts/crawl.py --out archive` | 腳本完成，等開放網域後執行 |
| 2. 逐篇分類 | `taxonomy/taxonomy.yaml` → `catalog.json` | 框架完成 |
| 3. 應用藍圖總覽 | `blueprint.md`（能力 × 工作流矩陣） | 待資料 |
| 4. 每篇落地產出 | `skills/<id>/SKILL.md` 或提示詞卡 | 待資料 |
| 5. 懶人包、實作手冊、宣傳圖文、商業提案簡報 | `deliverables/` | 待資料 |

## 關於原文封存

`archive/` 放全文與圖片，已列入 `.gitignore`，**只留在本機、不推上 GitHub**。原文版權屬於《數位時代》／巨思文化，封存只供個人閱讀。提交到版本庫的只有：中繼資料、自行撰寫的摘要與分類、原文連結，以及衍生的 skill 和流程。付費（一天一AI PRO）內容不在爬取範圍內。
